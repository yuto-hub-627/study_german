# 重要なこと

授業で先生が「重要」と言ったことを記録するフォルダです。
将来アプリに **「重要なこと」セクション（カードUI・まずはPC版のみ）** を作るときのデータ元になります。

## 記録のルール
- ユーザーから「重要なこと」として伝えられた内容は、`notes.md` に1件ずつ追記する
- 1件 = 1カード。下のフォーマットを守る（後でJSONに変換してカード表示するため）
- 新しいものを下に追加する。IDは連番（I-001, I-002 …）

### フォーマット
```
## I-001 タイトル（カードの見出し・短く）
- 日付: 2026-11-10
- 課: 4B（関係する課。なければ「-」）
- 分類: 文法 / 単語 / 発音 / テスト / その他
- 内容: 先生が言ったこと（そのまま or 要約）
- 例: Ich muss heute arbeiten.（任意）
- メモ: 補足（任意）
```
